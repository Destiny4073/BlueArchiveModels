01 模型来源

正在发现模型…

模型文件不随站点一起部署：页面部署在 Pages 分支（或 Actions 产物），模型留在 main 分支，由同源的 models.index.json 静态索引列出（npm run index 一次生成，日常访问零 API 请求，不受 GitHub 未认证接口 60 次/小时限流影响；点「刷新列表」或 ?live=1 才会重新扫线上目录）。模型字节走 ghproxy 前缀加速，逐个 HEAD 探测后自动选可用源，失败自动切换。配置见 models.config.json，也可用 ?repo=owner/repo&branch=main&dir=models 覆盖。仓库与 dist/ 均不内置任何模型文件；本地开发可自行放入 models/ 再用 npm run scan / ?scan=1，或直接选择本地文件、填写模型 URL。支持 glb / gltf / fbx / obj / stl / dae，可拖文件到画布，OBJ 可同时选中 .mtl。

逐帧渲染，直接复用右侧查看器的场景、材质、着色、描边、隐藏部件与相机，按所选帧率把当前动画从头到尾采样一次，帧不重复、时长不拉长；GIF 默认写入 NETSCAPE2.0 无限循环标记，播放器会反复播放这一段，取消「GIF 循环播放」才只播一次（文件名加 _once）。MP4 容器没有循环标记，是否循环由播放器决定。跟随鼠标运镜开启时，导出按真实时间推进（约等于动画时长），此时在右侧画布上拖动旋转、滚轮缩放、右键平移都会被逐帧采样进视频，右侧预览显示的正是正在录制的画面；0.5× 速度给你两倍时间做运镜，成片播放速度不变。关掉它则锁定导出开始时的视角并尽快渲染完。自定义画幅：宽、高各自独立设置（16–2048 px），横屏、竖屏、方形都可以；快捷画幅按钮以当前高度为基准换算宽度，「按预览比例」直接取右侧画布的宽高比，勾选「锁定当前宽高比」后改任一边另一边会等比跟随。导出相机保持垂直 FOV 不变，画幅宽度决定水平视野，所以与页面预览宽高比不同时构图会有差别。默认使用与页面一致的深色不透明背景；勾选上方选项才会输出透明 GIF。低分辨率抗锯齿：按输出短边判断，≤128 px 默认先以 4× 边长渲染，再逐级减半做 box 滤波缩小，消除 MSAA 样本不足造成的阶梯锯齿与描边断续；可在「抗锯齿」里关闭或指定 2× / 4×，不影响输出尺寸与帧数。宽高自动取偶数（H.264 要求），奇数输入会微调到最近的偶数并显示在状态里。GIF 帧延迟以 1/100 秒为单位，高帧率会被取整；分辨率和帧率越高，编码耗时与内存占用越大。
